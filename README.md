# 📱 React Native Todo App — Learn CRUD Operations

A beginner-friendly Todo application built with **React Native** to demonstrate fundamental **CRUD operations** — Create, Read, Update, and Delete.

This project is ideal for those learning how to:
- Manage state in React Native
- Build reusable components
- Handle user input effectively
- Store data persistently using **AsyncStorage**
- Work with conditional rendering and filtering

---

## 🧩 Features

- 📌 Add and manage todos
- ✅ Mark todos as complete/incomplete
- ✏️ Edit tasks inline
- 🗑️ Delete tasks
- 🔍 Filter by All, Active, and Completed
- 💾 Persistent storage using AsyncStorage
